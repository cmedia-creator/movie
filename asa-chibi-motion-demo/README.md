# Chibi Motion Demo

GitHub Pagesでそのまま公開できる、48秒の自動再生モーションデモです。

## 構成
- `index.html`
- `styles.css`
- `app.js`
- `assets/*.webp`

## 公開方法
このフォルダの中身をGitHubリポジトリ直下へアップロードし、GitHub Pagesを有効化してください。

## 動作
- 読み込み後に自動再生
- 約48秒
- デフォルトは自動ループ
- URL末尾に `?once=1` を付けると1回で停止
- 右上の `↻` または Space キーで最初から再生
- 9:16縦画面向け。PC・スマホ両対応
