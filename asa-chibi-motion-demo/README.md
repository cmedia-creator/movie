# 推しプロフ MVP v3

デザイン更新版です。

## テーマ
- 平成レトロ（前回OKだった案を維持）
- Y2K（クローム / ホログラム / シアン&マゼンタ）
- CYBER（グリッチ / RGBズレ / スキャンライン）
- BABYMON VIBE（ピンク&グレー / ステージポスター感）

## 参考にした方向性
- Y2K：AdobeのY2Kガイドにあるホログラフィック、ダーククローム、メタリック、レトロフューチャー感
- CYBER：Canvaのglitch/cyberpunk説明にあるグリッチ、RGB shift、デジタル歪み
- BABYMON VIBE：YG公式のビジュアル記事にある soft pink & gray / classic yet gentle / confident aura と、
  ユーザー共有のBABYMONSTER画像のピンク×ブラック系ポスター感

## 匿名ログイン
保存には Supabase の
Authentication → Sign In / Providers → Anonymous → ON → Save changes
が必要です。
