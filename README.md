## ファイルツリー

```text
/
├─ index.html
├─ life/
│  └─ index.html

```

## URL

GitHub Pagesを有効化すると、以下の構成になります。

- `/` : 作品一覧
- `/life/` : 「好きなものが、私をつくった。」
- `/scenario/` : 「物語は、素晴らしい。」

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / `(root)` を指定してください。

各作品は `index.html` 1ファイル構成なので、追加素材や外部ライブラリは不要です。
