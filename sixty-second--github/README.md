# 60 SECOND LIFE

TikTok画面録画向けに作った、約60秒の自動アニメーションです。

## 構成
- PROLOGUE：赤ちゃん
- CHAPTER 01：ヒーローに憧れる → 子どもへ
- CHAPTER 02：サッカーに夢中 → 少年へ
- CHAPTER 03：ゲームシナリオを書く → 大人へ
  - 選択肢は表示から3秒後に「続ける」が自動選択されます
- CHAPTER 04：妻と出会う → 二人で歩く
- EPILOGUE

## GitHub Pages
1. `index.html` をリポジトリ直下へアップロード
2. GitHub の `Settings` → `Pages`
3. `Deploy from a branch`
4. `main` / `(root)` を指定して保存

CSS、JavaScript、キャラクター、背景はすべて `index.html` 内に含めています。
外部素材・外部ライブラリは不要です。
